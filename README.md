# The Discord Account Takeover
**AP Cybersecurity classroom investigation · 60 minutes · beginner Linux · GitHub Codespaces**

A moderator at fictional **Pixel Harbor Gaming** receives an urgent account-verification DM. Minutes later, the account advertises a suspicious giveaway. You are junior incident responders: establish a timeline, separate facts from assumptions, and recommend a response.

Start with **STUDENT_WALKTHROUGH.md**. Teacher deployment instructions are in **SETUP.md**. This activity supports social engineering, authentication, evidence analysis, incident response, and technical communication; it is a teacher-created supplement, not an official College Board task or certified standards mapping.

## Quick start (after this repository opens in Codespaces)
```bash
bash scripts/setup.sh
bash scripts/check_lab.sh
```
No pip packages, API keys, Discord accounts, network scanning, or services are required. Read only the supplied fictional records. Never enter credentials or visit the example URLs.

## Included
- Nine evidence sources plus an inventory and SHA-256 baseline
- Beginner command walkthrough and independent challenge
- Fillable Markdown incident report template
- Optional Bash timeline script
- Teacher setup, answer key, rubric, and 60-minute lesson plan in the separate instructor package

All case events are UTC. Internet access is needed to create the Codespace and obtain its base image; investigation commands work on local files after setup. Student work stays in reports/ and working/ and is ignored by Git. Save/download your report before deleting the Codespace.
